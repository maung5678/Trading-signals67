เวอร์ชันปัจจุบัน: **v1.10** (ดู [ประวัติเวอร์ชัน](#ประวัติเวอร์ชัน))

| [`Experts/ST_TP_SL_EA.mq5`](Experts/ST_TP_SL_EA.mq5) | EA: ฝังอินดิเคเตอร์ไว้ข้างใน แล้วเปิดออเดอร์ตามป้าย BUY/SELL พร้อม SL / TP1–TP3 |

## EA ทำงานอย่างไร

1. EA โหลดอินดิเคเตอร์ (ฝังอยู่ในไฟล์ EA) บน **TF ที่ตั้งไว้** เช่น M15 ไม่ว่ากราฟจะเปิด TF ไหน
2. ทุกครั้งที่แท่งของ TF นั้นปิด EA อ่านป้ายจากอินดิเคเตอร์ ถ้ามีป้าย BUY / SELL บนแท่งที่ปิดแล้ว = เข้าออเดอร์
   **ป้ายบนกราฟกับจุดที่ EA เข้าออเดอร์มาจากโค้ดชุดเดียวกัน จึงตรงกันทุกแท่ง**
3. ราคา SL / TP ใช้ของแท่งสัญญาณ (ตรงกับเส้นบนกราฟ) แล้วปรับด้วยสเปรดสดตอนส่งออเดอร์
   - **SL** ถอยห่างจุดเข้าเพิ่มอีกเท่าสเปรด
   - **TP1 / TP2 / TP3** ขยับเข้าหาจุดเข้าเท่าสเปรด
   - ตัวอย่าง BUY ราคาปิด 2650.00 สเปรด 0.25: SL 2641.00 → ส่ง 2640.75, TP1 2659.00 → ส่ง 2658.75
   - ราคาที่ส่งจริงแสดงเป็นตัวเล็กสีจางข้างเส้นบนกราฟ
4. ถ้าตอนจะเข้า ราคาไปถึง TP1 แล้ว หรือชิด/เลย SL แล้ว EA ข้ามเทรดนั้นและแจ้งเหตุผล
5. มีป้ายฝั่งตรงข้าม → ปิดออเดอร์เดิมแล้วกลับฝั่ง (ปรับได้)

### แบ่งออเดอร์ตาม TP (EA ตรวจประเภทบัญชีเอง)

| บัญชี | วิธีทำ |
|---|---|
| **Hedging** (กดซื้อหลายครั้งได้หลายออเดอร์ โบรกรายย่อยส่วนใหญ่) | แยกเป็น 3 ออเดอร์ล็อตตามสัดส่วน TP1/TP2/TP3 ทุกออเดอร์ SL เดียวกัน **TP ทุกตัวอยู่ที่โบรก** ปิดให้แม้ MT5 ปิดอยู่ |
| **Netting** (1 คู่เงินมีได้ 1 ออเดอร์) | 1 ออเดอร์ ตั้ง SL และ TP ไกลสุด (TP3) ที่โบรก EA ปิดบางส่วนเองเมื่อถึง TP1 / TP2 (ต้องรัน MT5 อยู่) |

ตัวอย่าง ล็อตรวม 0.03 สัดส่วน 34/33/33 → 0.01 ที่ TP1, 0.01 ที่ TP2, 0.01 ที่ TP3
ล็อตรวมน้อยกว่า 3 เท่าของขั้นต่ำจะได้ไม่ครบ 3 ส่วน (0.01 → TP1 อย่างเดียว, 0.02 → TP1 + TP2)

### ออเดอร์ที่เปิดเองด้วยมือ

EA ไม่นับ ไม่ปิด และไม่แก้ออเดอร์ที่คุณเปิดเอง (แยกด้วย Magic number) บนบัญชี Hedging เทรดมือคู่กับ EA ได้ตามปกติ
บนบัญชี Netting โบรกรวมทุกออเดอร์ของคู่เดียวกันเป็นออเดอร์เดียว จึงไม่ควรเทรดมือคู่เดียวกับที่ EA รันอยู่

### หลายกราฟพร้อมกัน

วาง EA ได้หลายกราฟ แต่ละกราฟตั้ง TF ของตัวเอง เช่น EURUSD เทรด M5 และ XAUUSD เทรด M15
Magic number สร้างเองจากชื่อคู่ + TF (ช่อง Magic = 0) จึงไม่ปนกัน
ถ้าเปลี่ยน TF ที่เทรดขณะยังมีออเดอร์ค้าง Magic จะเปลี่ยน ออเดอร์เก่าจะไม่ถูกดูแลต่อ ให้ปิดออเดอร์ก่อนเปลี่ยน

## ติดตั้ง (คอมพิวเตอร์ Windows หรือ VPS)

> แอป MT5 บนมือถือ **รัน EA ไม่ได้** ต้องเปิด MT5 บนคอมหรือ VPS ทิ้งไว้
> (หรือใช้ VPS ของ MetaQuotes: คลิกขวาที่บัญชีใน Navigator → Register a Virtual Server)
> มือถือใช้ดูออเดอร์และรับแจ้งเตือนได้

1. MT5 → **File → Open Data Folder** → เข้าโฟลเดอร์ `MQL5`
2. คัดลอก `Indicators/ST_TP_SL.mq5` ไปที่ `MQL5\Indicators\`
   และ `Experts/ST_TP_SL_EA.mq5` ไปที่ `MQL5\Experts\`
3. เปิด **MetaEditor** (F4) → เปิด `ST_TP_SL.mq5` → **Compile** (F7) ต้องขึ้น `0 errors`
4. เปิด `ST_TP_SL_EA.mq5` → **Compile** (อินดิเคเตอร์ถูกฝังเข้าไปในไฟล์ EA ตอนนี้)
5. กลับ MT5 → เปิดกราฟคู่ที่ต้องการ (แนะนำให้ TF ตรงกับที่จะเทรด จะได้เห็นป้าย) → ลาก EA จาก Navigator มาวาง
6. แท็บ **Common** ติ๊ก **Allow Algo Trading** แท็บ **Inputs** ตั้งค่า → OK
7. ปุ่ม **Algo Trading** บนแถบเครื่องมือต้องเป็นสีเขียว

แจ้งเตือนเข้ามือถือ: MT5 คอม → Tools → Options → Notifications → ใส่ **MetaQuotes ID**
(ดูได้จากแอป MT5 มือถือ: Settings → Messages)

อัปเดตเวอร์ชันใหม่: คัดลอกไฟล์ทับของเดิม แล้ว compile อินดิเคเตอร์ก่อน ตามด้วย EA แล้ววาง EA ใหม่บนกราฟ

## ตั้งค่า (Inputs)

ส่วนที่ใช้ประจำอยู่บน ตัวเลือกเสริมอยู่ล่าง **ปิดไว้ทั้งหมด** เปิดใช้ทีละอย่างแล้ว backtest เทียบผล

### ตั้งค่าหลัก

| ตัวเลือก | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| TF ที่ใช้เทรด | M15 | EA เข้าตามแท่งของ TF นี้ ไม่ขึ้นกับ TF ของกราฟ |
| วิธีคิดล็อต | ตามเงินทุน | **ตามเงินทุน**: คิดล็อตให้ถ้าโดน SL จะเสีย % ที่ตั้งของบาลานซ์ / **ล็อตคงที่** |
| เสี่ยง % ต่อเทรด | 1.0 | ใช้กับโหมดตามเงินทุน ถ้าล็อตที่ได้ต่ำกว่าขั้นต่ำของโบรก EA ข้ามเทรดนั้น |
| ล็อตรวม | 0.03 | ใช้กับโหมดล็อตคงที่ (รวมทุก TP) |
| ล็อตรวมสูงสุด | 0 | เพดานกันพลาด (0 = ไม่จำกัด) |
| สัดส่วนปิดที่ TP1/TP2/TP3 | 34/33/33 | ตั้ง 0 = ไม่ใช้ TP นั้น เช่น 50/50/0 |
| ออเดอร์เดิมเมื่อเทรนด์กลับ | ปิดเมื่อมีป้ายตรงข้าม | หรือ ปิดทุกครั้งที่ Supertrend กลับทิศ / ไม่ปิด |
| Magic number | 0 | 0 = สร้างเองจากคู่ + TF |
| เข้าได้ภายในกี่ % ของแท่ง | 50 | กันเข้าป้ายเก่าตอนเพิ่งเปิด EA กลางแท่ง |
| แจ้งเตือนมือถือ / popup | เปิด / ปิด | เปิดออเดอร์, ถึง TP, โดน SL, ข้ามสัญญาณ, error |
| แสดงอินดิเคเตอร์บนกราฟ | เปิด | แสดงเมื่อ TF ของกราฟตรงกับ TF ที่เทรด |
| แสดงราคา SL/TP ที่ส่งจริง | เปิด | ตัวเล็กสีจางข้างเส้น |

### สัญญาณ / SL TP / การแสดงผล / แดชบอร์ด

เหมือนอินดิเคเตอร์บน TradingView: Factor 2.5, ATR 14, SL = ATR × 1.5, TP 1R / 2R / 3R
และสวิตช์แสดงป้าย เส้น โซน สีแท่งเทียน

แดชบอร์ด (เลือก เต็ม / ย่อ / ซ่อน และมุมจอได้):
- **สถิติชนะ/แพ้ของสัญญาณ**: เลือกช่วง 1 ชม. / 4 ชม. / 1 วัน / 1 สัปดาห์ / 1 เดือน / ทั้งหมด
  นับแบบเดียวกับ TradingView: ถึง TP1 ก่อน SL = ชนะ, โดน SL = แพ้ −1R, มีป้ายตรงข้ามก่อน = นับตาม R จริง
  เป็นสถิติของป้ายบนกราฟ ยังไม่หักสเปรดและค่าคอม
- **ADX**: ความแรงเทรนด์, แรงซื้อ/ขาย
- **เทรนด์หลายไทม์เฟรม**: M5 / M15 / H1 / H4 / D1
- **ประวัติเทรด**: 3 หรือ 10 เทรดล่าสุด (ค่าเริ่มต้นซ่อน)

### ตัวเลือกเสริม (ปิดทั้งหมด)

**บริหารออเดอร์**

| ตัวเลือก | ความหมาย |
|---|---|
| ถึง TP1 แล้วกันทุน (+ points) | เลื่อน SL ของออเดอร์ที่เหลือไปจุดเข้า |
| ถึง TP2 แล้วเลื่อน SL ไป TP1 | ล็อกกำไรเพิ่ม |
| Trailing stop ตามเส้น Supertrend | ทุกแท่งที่ปิด SL ขยับตามเส้น Supertrend (หักสเปรด) ขยับทางเดียว ไม่ถอยกลับ TP ไม่ขยับ |
| ใช้ Trailing แล้วไม่ตั้ง TP3 | ส่วนของ TP3 ไม่ตั้ง TP ปล่อยให้ trailing SL ปิดเมื่อเทรนด์จบ (TP1/TP2 ปิดตามปกติ) |

**ตัวกรองของ EA** (หยุดเฉพาะการเปิดออเดอร์ใหม่ ป้ายบนกราฟยังขึ้นตามปกติ)

| ตัวเลือก | ความหมาย |
|---|---|
| กรองสเปรด (% ของระยะ SL) | สเปรดกินเกิน % นี้ของระยะ SL ไม่เข้า แนะนำ 10% (เข้มงวด 5%, TF เล็ก 15–20%) ใช้ได้ทุกคู่โดยไม่ต้องตั้งใหม่ |
| เทรดเฉพาะช่วงเวลา | เวลาเซิร์ฟเวอร์ของโบรก รูปแบบ `08:00-22:00` ข้ามเที่ยงคืนได้ เช่น `22:00-06:00` |
| จำกัดขาดทุนต่อวัน | % ของบาลานซ์ หรือจำนวนเงิน (รวมออเดอร์ที่ยังเปิดอยู่) ถึงแล้วหยุดเปิดใหม่จนถึงวันใหม่ |
| จำกัดจำนวนเทรดต่อวัน | นับกลุ่มออเดอร์ที่เปิดต่อวัน |
| พักหลังโดน SL | ไม่เปิดใหม่กี่แท่งหลังโดน SL |
| หยุดเข้าช่วงข่าว | ใช้ปฏิทินเศรษฐกิจของ MT5 (ไม่ใช้ API ภายนอก) ข่าวสำคัญสูงของสกุลเงินในคู่นั้น เช่น XAUUSD ดูข่าว USD **ใช้ได้ตอนรันจริงเท่านั้น backtest ไม่ได้** |

**ตัวกรองสัญญาณของอินดิเคเตอร์** (เปลี่ยนป้ายบนกราฟด้วย): ADX แรง, เทรนด์ TF ใหญ่, EMA 200

**สัญญาณเพิ่ม**: เบรกเทรนด์ไลน์ / กรอบ, เข้าซ้ำหลัง TP3 (แตะ Supertrend / ตัด EMA / แตะ EMA แบบเร็ว)
หมายเหตุ: จุดกลับตัว (pivot) ยืนยันช้า N แท่ง เทรนด์ไลน์ที่เห็นย้อนหลังจึงดูแม่นกว่าตอนเทรดจริง

**เส้นบนกราฟ**: แนวรับ/แนวต้านแนวนอน, เทรนด์ไลน์ทแยง, กรอบราคา (แสดงอย่างเดียว)

**แดชบอร์ดผลงานจริงของ EA**: เงินจริงจากประวัติบัญชี (Magic เดียวกัน) วันนี้ / สัปดาห์ / เดือน / ทั้งหมด
หักสเปรด ค่าคอม swap แล้ว มักต่ำกว่าสถิติของป้าย ดูคู่กันเพื่อรู้ความจริง

## ทดสอบก่อนใช้เงินจริง

1. MT5 → **View → Strategy Tester** (Ctrl+R) → Expert: `ST_TP_SL_EA`, คู่, ช่วงวันที่
2. Modelling: **Every tick based on real ticks** → ติ๊ก Visual mode ถ้าอยากเห็นป้าย → Start
3. ต่อด้วย **บัญชี Demo** อย่างน้อย 1–2 สัปดาห์ ก่อนใช้บัญชีจริง

## ข้อควรรู้

- ราคาของโบรกต่างจาก feed ของ TradingView ป้ายบน MT5 อาจไม่ตรงกับ TradingView ทุกแท่ง
  แต่ป้ายบน MT5 ตรงกับที่ EA เข้าเสมอ
- ระบบเทรดอัตโนมัติขาดทุนได้ ตั้งขนาดความเสี่ยงให้เหมาะกับเงินทุนเสมอ

## สำหรับคนแก้โค้ด

EA ส่งค่าตั้งให้อินดิเคเตอร์ตาม **ลำดับ** ของ `input` ในอินดิเคเตอร์ (ยกเว้นกลุ่มสีท้ายไฟล์)
แก้ input ของไฟล์ใดไฟล์หนึ่งแล้วรัน

```
python3 mt5/tools/check_inputs.py
```

ต้องขึ้น `OK` ก่อน commit และเพิ่มเลขเวอร์ชัน (`#property version`, `IND_VERSION`, `EA_VERSION`) พร้อมบันทึกด้านล่าง
