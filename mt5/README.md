# EA สำหรับ MT5: Supertrend TP/SL (ออกออเดอร์อัตโนมัติ)

ไฟล์: [`ST_TP_SL_EA.mq5`](ST_TP_SL_EA.mq5)

EA ตัวนี้ใช้สูตรเดียวกับอินดิเคเตอร์ [`indicators/ST_with_TP_SL.pine`](../indicators/ST_with_TP_SL.pine)
และบอท [`bot/deriv_signal_bot.py`](../bot/deriv_signal_bot.py) แต่แทนที่จะแจ้งเตือน มันเปิดออเดอร์ใน MT5 ให้เลย
พร้อม SL และ TP1 / TP2 / TP3

## ทำงานอย่างไร

1. ทุกครั้งที่แท่งเทียนปิด EA คำนวณ Supertrend (ATR แบบ RMA เหมือน TradingView) จากแท่งย้อนหลัง
2. ถ้า Supertrend **กลับทิศบนแท่งที่ปิดแล้ว** = สัญญาณ (เหมือนป้าย BUY / SELL บนกราฟ ไม่ repaint)
3. ผ่านตัวกรอง (ADX, เทรนด์ TF ใหญ่, ฝั่งที่อนุญาต, สเปรด) แล้วเปิดออเดอร์ทันทีที่ต้นแท่งถัดไป
4. ระดับราคา (เหมือนอินดิเคเตอร์ แต่คิดจากราคาที่เข้าได้จริง)
   - **SL** = ราคาเข้า ∓ ATR × `SL = ATR ×` (ระยะนี้ = 1R)
   - **TP1 / TP2 / TP3** = ราคาเข้า ± 1R × ค่า R ของแต่ละ TP
5. เมื่อมีสัญญาณฝั่งตรงข้าม ปิดออเดอร์เดิมแล้วกลับฝั่ง (ปรับได้)

### แบ่งออเดอร์ตาม TP

| ประเภทบัญชี | วิธีทำ |
|---|---|
| **Hedging** (โบรกส่วนใหญ่ เช่น Exness, XM, IC Markets) | แยกเป็น 3 ออเดอร์ล็อตตามสัดส่วน TP1/TP2/TP3 ทุกออเดอร์ SL เดียวกัน โบรกปิดที่ TP ให้เองแม้ EA ไม่ได้รัน |
| **Netting** | 1 ออเดอร์ ตั้ง TP ไกลสุด EA ปิดบางส่วนเองเมื่อราคาถึง TP1 / TP2 (ต้องรัน EA อยู่) |

ตัวอย่าง ล็อตรวม 0.03 สัดส่วน 34/33/33 → 0.01 ที่ TP1, 0.01 ที่ TP2, 0.01 ที่ TP3
ถ้าล็อตรวมน้อยกว่า 3 เท่าของขั้นต่ำ จะเหลือไม่ครบ 3 ส่วน (0.01 → TP1 อย่างเดียว, 0.02 → TP1 + TP2)

## ติดตั้ง (ทำบนคอมพิวเตอร์ Windows หรือ VPS)

> แอป MT5 บนมือถือ **รัน EA ไม่ได้** ต้องเปิด MT5 บนคอมหรือ VPS ทิ้งไว้ตลอด
> (หรือใช้ VPS ของ MetaQuotes: คลิกขวาที่บัญชีใน Navigator → Register a Virtual Server)
> มือถือใช้ดูออเดอร์และรับแจ้งเตือนได้

1. MT5 → **File → Open Data Folder** → เข้าโฟลเดอร์ `MQL5\Experts`
2. คัดลอก `ST_TP_SL_EA.mq5` ไปวางในโฟลเดอร์นั้น
3. เปิด **MetaEditor** (F4) → เปิดไฟล์ → กด **Compile** (F7) ต้องขึ้น `0 errors`
4. กลับ MT5 → เปิดกราฟคู่เงินและ TF ที่ต้องการ → ลาก EA จาก Navigator (Expert Advisors) มาวางบนกราฟ
5. แท็บ **Common** ติ๊ก **Allow Algo Trading** แท็บ **Inputs** ตั้งค่า → OK
6. ปุ่ม **Algo Trading** บนแถบเครื่องมือต้องเป็นสีเขียว มุมขวาบนของกราฟจะเห็นไอคอนหมวกสีฟ้า

แจ้งเตือนเข้ามือถือ: MT5 คอม → Tools → Options → Notifications → ใส่ **MetaQuotes ID**
(ดูได้จากแอป MT5 มือถือ: Settings → Messages) แล้วเปิด `ส่งแจ้งเตือนเข้าแอป MT5 มือถือ` ใน EA

## ตั้งค่า (Inputs)

**สัญญาณ**: `Factor`, `ATR`, `SL = ATR ×`, `TP1–TP3 (R)` ตั้งให้ตรงกับอินดิเคเตอร์บน TradingView
`TF ของสัญญาณ` = CURRENT ใช้ TF ของกราฟที่วาง EA

**ตัวกรอง**

| ตัวเลือก | ความหมาย |
|---|---|
| เข้าเฉพาะตอน ADX แรง / เกณฑ์ ADX | เหมือน "สัญญาณเฉพาะตอน ADX แรง" ในอินดิเคเตอร์ |
| กรองด้วยเทรนด์ TF ใหญ่ | BUY เฉพาะตอน Supertrend ของ TF ใหญ่ (แท่งที่ปิดแล้ว) เป็นขาขึ้น SELL เฉพาะขาลง |
| อนุญาตฝั่ง BUY / SELL | เช่น Boom ให้เปิดแค่ BUY |
| สเปรดสูงสุด | สเปรดกว้างกว่านี้ไม่เข้า (0 = ไม่เช็ก) |
| เข้าได้ภายในกี่ % ของแท่ง | กันเข้าสัญญาณเก่าตอนเพิ่งเปิด EA กลางแท่ง |

**ขนาดออเดอร์**

- `ล็อตคงที่`: ล็อตรวมทุก TP เช่น 0.03
- `เสี่ยง % ของบาลานซ์`: คำนวณล็อตให้ถ้าโดน SL จะเสียประมาณ % นี้ของบาลานซ์
  ถ้าล็อตที่ได้ต่ำกว่าขั้นต่ำของโบรก EA **ข้ามเทรดนั้น** (ไม่ฝืนเปิดเกินความเสี่ยง)
- `ล็อตรวมสูงสุด`: เพดานกันพลาด
- `สัดส่วนปิดที่ TP1/TP2/TP3`: ตั้ง 0 เพื่อไม่ใช้ TP นั้น เช่น 50/50/0 = ปิดครึ่งที่ TP1 ครึ่งที่ TP2

**บริหารออเดอร์**

| ตัวเลือก | ความหมาย |
|---|---|
| ออเดอร์เดิมเมื่อเทรนด์กลับ | ปิดเมื่อมีสัญญาณตรงข้ามที่ผ่านตัวกรอง (ค่าเริ่มต้น เหมือนสถิติของอินดิเคเตอร์) / ปิดทุกครั้งที่ Supertrend กลับทิศ / ไม่ปิด |
| ถึง TP1 แล้วกันทุน | เลื่อน SL ของออเดอร์ที่เหลือไปที่ราคาเข้า (+ points ที่ตั้ง) |
| ถึง TP2 แล้วเลื่อน SL ไป TP1 | ล็อกกำไรเพิ่ม |

ค่าเริ่มต้นของการกันทุนคือ **ปิด** เพื่อให้ผลตรงกับสถิติบนอินดิเคเตอร์ (SL เดิมจนจบเทรด)

**อื่น ๆ**: `Magic number` ใช้แยกออเดอร์ของ EA ออกจากออเดอร์ที่เปิดเอง
ถ้าวาง EA หลายกราฟคู่เงินเดียวกันแต่คนละ TF ให้ใช้ Magic คนละเลข

## ทดสอบก่อนใช้เงินจริง

1. MT5 → **View → Strategy Tester** (Ctrl+R) → เลือก `ST_TP_SL_EA`, คู่เงิน, TF, ช่วงวันที่
2. Modelling: **Every tick based on real ticks** (แม่นสุด) → Start
3. ดูแท็บ Graph / Backtest / Journal
4. ต่อด้วย **บัญชี Demo** อย่างน้อย 1–2 สัปดาห์ ก่อนใช้บัญชีจริง

## ข้อควรรู้

- สัญญาณอาจไม่ตรงกับ TradingView 100% เพราะราคาของโบรกต่างจาก feed ของ TradingView
  (ใช้กราฟโบรกเดียวกันบน TradingView ถ้ามี เช่น `EXNESS:XAUUSD`) และ ATR ต้องใช้แท่งย้อนหลังพอ (ค่าเริ่ม 1000 แท่ง)
- ราคาเข้าจริง = ราคา Ask/Bid ตอนเปิดแท่งถัดไป ไม่ใช่ราคาปิดของแท่งสัญญาณ SL/TP คิดจากราคาเข้าจริงโดยใช้ระยะ R เดิม
- EA ยังไม่รองรับสัญญาณเสริมของอินดิเคเตอร์: เบรกเทรนด์ไลน์ / กรอบ, เข้าซ้ำหลัง TP3, ตัวกรอง EMA 200
- EA จำสัญญาณที่ทำไปแล้ว (Global Variables ของ MT5) ปิดเปิด MT5 ใหม่จะไม่เข้าซ้ำแท่งเดิม
- ความเสี่ยง: ระบบเทรดอัตโนมัติขาดทุนได้ ทดสอบและตั้งขนาดล็อตให้เหมาะกับเงินทุนเสมอ
